# LiveScope design system

Product: LiveScope. Tagline: Observe. Reproduce. Fix. Verify.
Audience: engineers who run production services.
Job of this page: explain what LiveScope does, the reliability loop, and the three planes. It is an information site, not a signup funnel and not a pricing page.

## Visual direction

Dark developer-tool canvas. Near-black ground `#07080a`. The only chroma is a warm aurora: crimson `#ff2f3a` through coral `#ff6b4a` into amber `#ffb347`. No purple, indigo, or violet. No stock photos.

Type: Inter for all UI. Hierarchy from size and weight. One headline word may use the warm text gradient. Geist Mono only for short technical captions, topic names, and command chips.

Shape: flat, except keycap-raised near-white buttons (`#e6e6e6` fill, `#2f3031` text, 8px radius, layered shadow) and dark-glass panels (backdrop blur, 1px hairline border, about 14px radius).

Nav: a floating pill, not a full-bleed bar. Wordmark left, muted links, one near-white pill.

## Page structure

1. Floating pill nav: LiveScope, What it does, The loop, Planes.
2. Hero: eyebrow, two-line headline with one warm word, one-sentence subtitle, two keycap actions (Read the loop, See the planes), a mono caption.
3. A dark-glass panel that shows the loop as a command list, not a generic feature grid: Observe, Detect, Investigate, Reconstruct, Compare fixes, Execute, Verify.
4. Three planes: Data, Control, AI. Each is a glass card with one sentence and a trust note.
5. What it answers: five short questions (what is broken, why, what if we change X, which fix is safest, did it work).
6. Footer with the wordmark and the tagline.

Copy stays concrete. Do not invent customers, prices, or download buttons for macOS.
